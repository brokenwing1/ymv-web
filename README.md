# YMV Painting Lab

Готовая локальная демонстрация одностраничного сайта кузовной студии в Калининграде. HTML, CSS и JavaScript, без фреймворка, backend, базы данных и обязательной установки npm-пакетов.

## Запуск

Требуется Node.js 18 или новее.

```sh
npm run dev
```

Открыть http://localhost:5173. Сервер слушает только локальный интерфейс. Другой порт: установить переменную окружения `PORT` перед запуском. Остановить сервер — Ctrl+C.

```sh
npm run check
npm run build
```

`check` проверяет ресурсы, якоря, дублирующиеся id и синтаксис JS. `build` копирует публичные файлы в `dist/`, исключая исходные JPEG. Содержимое `dist/` можно разместить на обычном статическом хостинге. Публикация не выполнялась.

## Структура

- `index.html` — все секции, модальные окна, семантика и SEO.
- `styles/main.css` — адаптивная сетка, фирменная палитра, анимации.
- `scripts/config.js` — контакты, адрес, координаты и изображения сравнения.
- `scripts/main.js` — меню, раскрывающиеся услуги, галерея, сравнение, форма, карта.
- `assets/` — локальные WebP, шрифты, favicon и MapLibre GL JS 5.24.0.
- `tools/` — сервер, сборка, проверка ресурсов.

## Что работает

Фиксированная навигация, мобильное меню, якоря, раскрывающийся список из восьми услуг, галерея с просмотром фото, сравнение до/после мышью, касанием и клавиатурой, форма с выбором услуги и валидацией, подготовка и копирование текста заявки, интерактивная карта с маркером. Модальные окна поддерживают Escape, возврат фокуса и встроенное ограничение фокуса. Есть skip-link, видимый фокус, reduced motion, ленивые изображения и загрузка карты при приближении к секции.

## Перед показом владельцу

В исходной папке не было фотографий или Instagram-скриншотов. Использованы локальные стоковые фотографии; они подписаны как демонстрационные и **не являются работами YMV**. Источники указаны в `assets/CREDITS.md`.

Компонент до/после сейчас показывает **один кадр с разной CSS-обработкой**, а не реальный результат ремонта. Для настоящего сравнения укажите два совмещённых по ракурсу снимка в `comparison.before` и `comparison.after`, поставьте `comparison.demo: false` и замените `comparison.caption`.

В `scripts/config.js` заполните:

```js
const BUSINESS_ADDRESS = "Подтверждённый адрес";
// В объекте YMV_CONFIG:
phone: "+7 ...",
telegram: "https://t.me/...",
whatsapp: "https://wa.me/...",
instagram: "https://www.instagram.com/...",
coordinates: [/* широта, долгота */],
```

Неизвестные контакты оставлены пустыми, не ведут на вымышленные аккаунты. Пока адрес не подтверждён, карта показывает **условную точку района**, что указано на маркере и под картой. Карта работает на MapLibre GL JS 5.24.0 с тёмным векторным стилем OpenFreeMap, без API-ключа. Библиотека загружается локально по мере приближения к контактам. Интернет нужен для картографических данных и внешних ссылок; изображения, шрифты и код локальные.

Форма **не отправляет заявку**: она формирует текст для копирования. Данные не записываются в localStorage, cookie или на сервер. Подтверждённые социальные ссылки автоматически появляются после подготовки заявки. Для настоящего приёма заявок потребуется отдельно подключить канал доставки и согласовать обработку персональных данных. После обновления материалов также замените текст демонстрационного уведомления в `index.html`; флаг `demo` зарезервирован для дальнейшей интеграции и сам по себе не снимает подписи.

## Проверка

Проверка в headless Microsoft Edge через Playwright: экраны 320, 390, 768, 1440, 1920 px, отсутствие горизонтального переполнения, загрузка изображений, услуги, выбор услуги в форме, подготовка заявки, закрытие модальных окон, галерея, клавиатурное сравнение, карта, мобильное меню, reduced motion. Снимки и временный сценарий находятся в игнорируемой папке `.qa/`.
